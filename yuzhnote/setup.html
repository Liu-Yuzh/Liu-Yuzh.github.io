書誌取得ブリッジの入れ方

YuzhNote で、openBD にない本を国立国会図書館サーチと版元ドットコムでも探したり、自分のツイートのスレッドをさかのぼって引用したりするためのブラウザ拡張です。入れなくても、openBD にある本の書誌と、ツイート1件ずつの引用は入ります。

パソコン（Firefox）

  1. Tampermonkey を Firefox に追加する。
  2. 下の「ブリッジを入れる」を開くと Tampermonkey の画面が出るので、「インストール」を押す。
  3. YuzhNote のページを開き直す。

ブリッジを入れる

iPhone（Safari）

  1. App Store で「Userscripts」（無料）を入れる。
  2. 設定アプリ → Safari → 機能拡張 → Userscripts をオンにし、「scrapbox.io」と「liu-yuzh.github.io」を許可する。
  3. Safari でこのページの「ブリッジを入れる」を開き、アドレスバーの「ぁあ」（または拡張ボタン）→ Userscripts →「Install」を押す。
  4. Cosense を Safari で開き直す。初回はアクセスの許可を求められたら「許可」する。

ホーム画面から開いた Cosense（Web アプリ）では拡張が動かないことがあります。書誌を入れるときは Safari で開いてください。

Android（Chrome）

Chrome は拡張が使えないため、Firefox for Android に Tampermonkey を入れて、パソコンと同じ手順で入れてください。

このブリッジがしていること

YuzhNote（scrapbox.io/YuzhNote）の中だけで動き、Cosense の UserScript から頼まれたときに、次の 3 つのサイトのページを読んで渡します。読むだけで、送信やログイン情報の受け渡しはしません。

  1. ndlsearch.ndl.go.jp（国立国会図書館サーチ）… 書誌
  2. www.hanmoto.com（版元ドットコム）… 書誌
  3. cdn.syndication.twimg.com（X の埋め込み用データ）… 自分のツイートのスレッドをさかのぼるため

ブラウザは安全のため、あるサイト（Cosense）から別のサイトの中身を読むことを制限しています（CORS）。これらのサイトはその許可を出していないので、拡張の権限で読んでいます。

1.0.0 を入れた方へ：Tampermonkey は自動で更新されます（すぐ更新したいときは、もう一度「ブリッジを入れる」から入れ直してください）。iPhone の Userscripts は入れ直してください。
